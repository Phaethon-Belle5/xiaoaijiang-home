## 设计特异性裁决

中偏上。星界玻璃图书馆概念专属难移植；骨架（轮播 hero → 分区 → 页脚）通用。错失：hero 三 slide 共用壁纸、CTA 全指向 content；旅行内容被埋三层钻取后，桌宠最抢戏；双 accent 未延伸成叙事。

确定性扫描（B）：CLI 114 命中 = 6 warning + 108 advisory。warning：渐变文字、弹跳缓动、2 处动画布局属性、灯箱空 src、金辉。浏览器运行时额外检出：gpt-thin-border-wide-shadow、low-contrast（3.3:1）、kicker-above-heading、skipped-heading、repeating-stripes-gradient。108 条 advisory 绝大多数是 DESIGN.md YAML 令牌表未收录遮罩/管理面板/图表色/微圆角，属令牌化缺口而非设计错误；渐变文字/灯箱空 src/eqbounce/pill 指示器/金辉按 DESIGN.md 是有意设计。

覆盖层：detect.js 在 headless Edge 注入成功（home 18 / content 20 / gallery 16），本会话无用户可见浏览器 tab。

## 整体印象

站点的「脸」很好（专属、精致、有灵魂）；「骨架」超载（功能密度、浮层、入口太多）。最大机会：理顺右下角浮层与轮播被动翻页，让访客有空间读你。

## 表现好的地方

1. 连贯且专属的视觉身份（玻璃+金+星芒角+Cinzel；墨色反白导航指示器执行 One Accent Rule）
2. 有灵魂的个性化内容（桌宠/meme 成就卡/宇宙地址/便利贴说说）
3. 交互完整度（Escape/方向键/focus-visible/reduced-motion/空态/懒加载失败提示）

## 优先问题

[P0] CSS 全局重置清掉所有按钮底色（line 214）：`button,.btn,.slide-cta,input,textarea,select,…{background:initial!important}` 连带清掉元素背景。实测管理面板金色保存按钮对比 1.1:1 几乎不可见；音乐播放键、CTA 按钮失去 affordance。修法：只重置 `-webkit-text-fill-color:initial!important`，删掉 `background:initial!important`，回归所有按钮背景。→ polish

[P1] 轮播 6s 自动播放不暂停 + 三 slide 共用壁纸 + CTA 全指向 content：打断阅读、视觉单调、轮播退化成翻页。修法：hover/focus/visibilitychange 暂停；slide 各自背景；CTA 分工。→ animate + layout

[P1] 右下角浮层交叠（桌宠/音乐 FAB/壁纸控制/返回顶部 4 个交互点挤角落；移动端底部 5 浮层）。修法：壁纸控制并入面板；桌宠挪位；右下只留 FAB。→ layout

[P1] 映像馆三套并行照片浏览 + 无引导三层钻取（地图/引力/灯箱/未标注四入口；照片面板掉出视口）。修法：加引导文案 + scrollIntoView；评估引力相册降级。→ clarify + layout

[P1] 弱文字对比度 3.3:1（#6B6458 on #0B0E14，footer/eyebrow 小字，浅色 3.6:1）低于 WCAG AA 4.5:1。修法：提高 --text-muted 亮度或加粗。→ audit

[P2] 管理面板 10-tab 移动端溢出（390px 仅 5 tab 可见）+ 文案 Tab 23 字段单滚。修法：合并 tab、可折叠分区、滚动淡出提示。→ adapt
